DSH Desktop Control 0.2.5 · Windows x64 测试版

需要 DSH Desktop 0.2.1-rc.2、dsh-plugin-hub 1.0.0、Windows PowerShell 5.1。
不需要本地大模型、Python、额外 API Key 或联网下载依赖。

1. 源码目录可直接运行安装 CMD，保留 lib、vendor、skills 和 tools。
2. 运行“检查环境.cmd”。
3. 从托盘完全退出 DSH，再运行“安装.cmd”。
4. 重新打开 DSH，在扩展口袋或设置中找到“桌面操作”。
5. 卸载前同样完全退出 DSH，再运行“卸载.cmd”。

普通权限须明确授权当前任务，并在 DSH 原生批准卡片核对目标窗口；完全访问免首次审批。
普通任务仍优先 API、文件或命令行；明确指定桌面操作/验收时，指定步骤应实际使用 desktop_* 工具。
操作会短暂占用真实鼠标、键盘与焦点；请监督执行。
所有目标统一先还原/置前，必要时自动最小化实际遮挡目标的普通窗口，再观察操作；不关闭程序。
被收起窗口的原状态随工具结果记录，任务结束不全局还原覆盖结果。
Esc 或 Ctrl+Alt+F12 可停止操作；也可在插件设置中暂停全部工具。
Esc 后所有模式均保持停止、撤销旧令牌；用户要求继续时须通过原生“恢复桌面控制”确认。
恢复确认与普通工具审批通道独立，不切换全局权限模式；确认后立即刷新权限，无需等待或重启。
恢复确认是工作台内嵌的紧凑卡片，只提供“保持停止”和“恢复任务”两个按钮，无自由回答。
取消或确认通道不可用则保持停止，换轮次和重启不能自行恢复。恢复后重新观察，不能重放旧输入。
组合热键、多应用及复杂恢复场景的覆盖仍有限。
0.2.5 增强透明桌宠、分层浮层和任务栏过渡下的有界焦点恢复，仍须实际取得目标前台后才允许输入。
明确未发送输入的焦点准备失败会保留引擎与任务授权、清除旧观察，不要求重载技能。
可沿用有效任务令牌显式调用一次 desktop_activate，再重新观察；若仍失败则停止报告，不反复激活。
Esc、暂停、超时、真正遮挡与结果未知的输入仍按原规则处理；不绕过安全软件保护。
图片模型须在 DSH 模型配置声明 input: [text, image]；仅使用 UIA 树不等于视觉验收通过。
截图、OCR 与界面文字将交给当前会话的云端模型供应商。
仅适用于当前交互桌面中可还原/置前的目标；不保证 UAC、锁屏、安全桌面等场景。

详细用法和限制：README.md。
