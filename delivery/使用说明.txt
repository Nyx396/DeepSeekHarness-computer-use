DSH Desktop Control 0.1.5 · Windows x64 测试版

需要 DSH Desktop 0.2.1-rc.2、dsh-plugin-hub 1.0.0、Windows PowerShell 5.1。
不需要本地大模型、Python、额外 API Key 或联网下载依赖。

1. 完整解压 ZIP，保留 plugin 和 tools 目录，不在压缩包内直接运行。
2. 运行“检查环境.cmd”。
3. 从托盘完全退出 DSH，再运行“安装.cmd”。
4. 重新打开 DSH，在扩展口袋或设置中找到“桌面操作”。
5. 卸载前同样完全退出 DSH，再运行“卸载.cmd”。

工具使用前须获得当前任务的明确授权，并在 DSH 原生批准卡片核对目标窗口。
操作会短暂占用真实鼠标、键盘与焦点；请监督执行。
Esc 或 Ctrl+Alt+F12 可停止操作；也可在插件设置中暂停全部工具。
物理停止热键尚未完成正式人工验收，当前为有人监督的测试版。
截图、OCR 与界面文字将交给当前会话的云端模型供应商。
仅适用于可见、未最小化的普通桌面窗口；不保证 UAC、锁屏、安全桌面等场景。

详细用法和限制：plugin/README.md。
许可证：plugin/LICENSE；第三方来源：plugin/THIRD_PARTY.md。
安装前会备份旧插件及相关配置；失败自动尝试回滚。
备份位于 <DSH_HOME>/backups/dsh-desktop-control/。

SHA256SUMS.txt 为包内逐文件 SHA-256；ZIP 旁的 .sha256.txt 为整包校验值。
本 ZIP 不包含本机验证记录、测试任务、日志、截图或宿主运行时副本。
尚未上传到任何仓库，也未通过 npm 发布。
